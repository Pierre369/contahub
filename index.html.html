🔌 Integração Mercado Pago (passo a passo)

Modo demonstração
Configure o backend abaixo para aceitar PIX reais.

1 Criar conta e pegar credenciais

  • Crie sua conta no mercadopago.com.br (aceita CPF, sem CNPJ).
  • Vá em Seu negócio → Configurações → Credenciais.
  • Copie o Access Token (use o de produção quando for cobrar de verdade; o de teste serve para treinar).
⚠️ O Access Token fica somente no servidor (variável de ambiente). Nunca coloque no código do site.

2 Backend: criar pagamento PIX

Crie o arquivo api/criar-pagamento.js na Vercel (Serverless):

// api/criar-pagamento.js
export default async function handler(req, res) {
  const { valor, email, orderId } = req.body  // valor em REAIS

  const r = await fetch('https://api.mercadopago.com/v1/payments', {
    method: 'POST',
    headers: {
      Authorization: 'Bearer ' + process.env.MP_ACCESS_TOKEN,
      'Content-Type': 'application/json',
      'X-Idempotency-Key': orderId   // evita cobrança duplicada
    },
    body: JSON.stringify({
      transaction_amount: Number(valor),
      payment_method_id: 'pix',
      description: 'Compra ContaHub - ' + orderId,
      payer: { email },
      external_reference: orderId
    })
  })
  const d = await r.json()
  res.json({
    id: d.id,
    qrCode: d.point_of_interaction.transaction_data.qr_code,
    qrBase64: d.point_of_interaction.transaction_data.qr_code_base64
  })
}

3 Backend: webhook (confirmação automática)

Crie api/webhook.js e registre a URL no painel MP (Seu negócio → Webhooks → Pagamentos):

// api/webhook.js
export default async function handler(req, res) {
  res.status(200).send('ok')   // responde rápido
  const id = req.query.id || req.body?.data?.id
  if (!id) return

  // 1) Busca o pagamento direto na API (nunca confia no body)
  const r = await fetch('https://api.mercadopago.com/v1/payments/' + id, {
    headers: { Authorization: 'Bearer ' + process.env.MP_ACCESS_TOKEN }
  })
  const p = await r.json()

  // 2) Se aprovado, libera o pedido no banco de dados
  if (p.status === 'approved') {
    const orderId = p.external_reference
    // → supabase.from('orders').update({ status:'pago' }).eq('id', orderId)
  }
}
✅ Com o webhook funcionando, este site passa a confirmar pagamentos automaticamente — sem ninguém clicar em "já paguei".

  • O valor das vendas fica na sua conta Mercado Pago (Escrow).

🚀 Guia rápido de produção

Resumo do caminho para transformar este protótipo em produto real. O detalhe do Mercado Pago está no painel Integração MP.

1 Estrutura recomendada (grátis)

  • Vercel → hospeda o site + as funções de pagamento (Serverless)
  • Supabase → login real, banco de dados e armazenamento de imagens
  • Mercado Pago → PIX, cartão, boleto (aceita CPF)
  • Registro.br + Cloudflare → domínio próprio + HTTPS

2 Banco de dados (SQL essencial)

create table profiles (
  id uuid primary key, nome text,
  chave_pix text, saldo numeric default 0
);
create table listings (
  id uuid primary key, seller uuid references profiles.id,
  categoria text, titulo text, descricao text,
  preco numeric, status text default 'ativo'
);
create table orders (
  id uuid primary key, buyer uuid references profiles.id,
  listing uuid, valor numeric, status text,
  mp_payment_id text, credenciais jsonb
);
create table withdrawals (
  id uuid primary key, seller uuid references profiles.id,
  valor numeric, chave_pix text,
  status text default 'pendente'
);

3 Segurança obrigatória

  • Access Token só no servidor (env da Vercel)
  • Webhook sempre re-busca o pagamento na API (nunca confia no body)
  • RLS ativo no Supabase (cada usuário vê só o que é dele)
  • HTTPS via Cloudflare + validação de todos os inputs
  • KYC simples do vendedor (nome + CPF + chave PIX) antes do 1º saque

4 Ordem de execução

  • Criar contas: Vercel, Supabase, Mercado Pago
  • Subir este site na Vercel
  • Rodar o SQL no Supabase + ativar RLS
  • Trocar o login demo pelo Supabase Auth
  • Publicar as 2 funções de pagamento + webhook
  • Colar a URL do backend no painel Integração MP
  • Testar com R$ 1,00 e lançar 🎉
